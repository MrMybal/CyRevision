# CyRevision Lore Companion (experimental)

This source-only Unreal Editor companion exposes a small Lore workspace panel and a shortcut to CyRevision.
It is installed per project by the optional `Lore Project Management` plugin in CyRevision.

This companion is **not** Epic Games' official Unreal Editor Lore source-control provider. Epic's public Lore
roadmap currently schedules that provider separately. Lore remains an external CLI/server dependency.

Supported target range: Unreal Engine 4.27 through 5.8 for source projects. A compatible C++ toolchain is
required to compile project plugins.
