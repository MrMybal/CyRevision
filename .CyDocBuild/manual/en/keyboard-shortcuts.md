## Default shortcuts {#default-shortcuts}
- F1: help for the active view; F5: refresh the project.
- Ctrl+,: Preferences.
- Ctrl+O: open repository; Ctrl+Shift+O: add folder.
- Ctrl+N: create repository; Ctrl+Shift+N: clone.
- Ctrl+1 / 2 / 3 / 4: Changes / History / Branches / Pull Requests.
- Ctrl+Shift+F: code search.
- Ctrl+Alt+F / L / P: Fetch / Pull / Push.
- Ctrl+Q: request application exit.

Defaults can be customized in Preferences. Operating-system/global shortcuts may intercept a key first. A shortcut is not a bypass for confirmations, missing permissions or incompatible project modes.

Inside this documentation window, Ctrl+K opens global search. Tab and Enter navigate controls; Left/Right collapse or expand topic branches. Escape closes search or reduces an enlarged illustration. These reader controls are separate from the application's configurable shortcuts.

## Focus and editing {#focus-and-editing}
Use Tab/Shift+Tab to move through keyboard-navigable controls. Text editors retain their normal editing keys; global commands must not unexpectedly interpret typed text. Commit/cancel a draft explicitly before discarding its context.

## Layout and readability {#layout-and-readability}
Resize table columns and windows, use horizontal scroll for long paths/logs and detach dense panels. Increase density/font/DPI settings where supported and choose a high-contrast theme. Color is a supplementary signal: read state labels as well. If a panel goes offscreen, use View > Reset panel layout. Report the platform, display scaling and exact view for persistent clipping.
