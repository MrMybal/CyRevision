## Projects and workspaces {#projects-and-workspaces}

The left sidebar contains projects only. Select a project to make it active; its name, branch, mode and counters appear in the header. Groups organize the catalogue without moving files. A scan can continue in the background while another project is selected.

## Open a view {#open-a-view}

1. Select a category such as Git or Code & Assets.
2. Select its second-level tab, for example History or Solution Explorer.
3. Use View > Detach current tab, the Detach action or a tab's context menu to open an auxiliary window.
4. Use View > Open windows to focus an existing window or close auxiliary views.

Detached views share the active project's services; they are not independent copies of a repository. Check the project header before an action. Closing a view does not delete project data.

## Tables and loading {#tables-and-loading}

Drag a column separator to resize, drag a header to reorder and use the header context menu to hide columns where offered. Horizontal scrolling exposes long paths. Orange identifies the selected tab; action buttons belong to the toolbar. A spinner or loading label indicates an outstanding request. Cancel affects the current cancellable operation, not completed work.
