## Project identity {#project-identity}
Overview > Project provides display name, color and sidebar group. These catalogue settings organize CyRevision; changing the display name does not rename the repository folder or hosted project. Review the displayed path before opening/removing a project.

## Notifications {#notifications}
Overview > Notifications lists the selected project's events. Sidebar badges indicate unread items, not necessarily failures. Read the event type/details and mark handled/read through the offered controls. Task details is the operation history, not the same list as project notifications.

## Visible tabs {#visible-tabs}
Overview > Visible tabs controls which available pages appear. A plugin/mode can make a page unavailable even if you want it visible. Restore visibility rather than resetting all application preferences when only one tab is hidden.

## License {#license}
Overview > License shows the project's license information and any supported configuration. CyRevision's application license and third-party notices are separate from the license of your own repository. Review the appropriate license files before distributing plugins or assets. A license label in the interface does not grant rights you do not hold.

Removing a project from the catalogue is not a request to delete its original source files; inspect any optional generated-cache cleanup separately.
