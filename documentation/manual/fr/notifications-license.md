## Identité du projet {#project-identity}
Overview > Project propose nom d'affichage, couleur et groupe latéral. Ce sont des réglages de catalogue : renommer l'affichage ne renomme ni dossier ni projet hébergé. Vérifiez le chemin avant ouverture/retrait.

## Notifications {#notifications}
Overview > Notifications liste les événements du projet actif. Un badge indique du non-lu, pas nécessairement un échec. Lisez type/détails puis marquez lu/traité avec les contrôles proposés. Task details affiche les opérations, une liste différente.

## Onglets visibles {#visible-tabs}
Overview > Visible tabs règle l'affichage des pages disponibles. Un plugin/mode peut rendre une page indisponible même si vous la souhaitez visible. Rétablissez la visibilité plutôt que réinitialiser toutes les préférences pour un onglet masqué.

## Licence {#license}
Overview > License montre les informations et réglages de licence proposés. Licence de CyRevision/notices tierces et licence de votre dépôt sont distinctes. Lisez les fichiers concernés avant de distribuer plugins ou assets. Un libellé ne vous accorde pas des droits que vous n'avez pas.

Retirer un projet du catalogue ne demande pas de supprimer ses sources originales ; examinez séparément un éventuel nettoyage de cache généré.
