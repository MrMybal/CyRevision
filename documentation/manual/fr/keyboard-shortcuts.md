## Raccourcis par défaut {#default-shortcuts}
- F1 : guide ; F5 : actualiser le projet.
- Ctrl+, : préférences.
- Ctrl+O : ouvrir un dépôt ; Ctrl+Maj+O : ajouter un dossier.
- Ctrl+N : créer un dépôt ; Ctrl+Maj+N : cloner.
- Ctrl+1 / 2 / 3 / 4 : Changes / History / Branches / Pull Requests.
- Ctrl+Maj+F : recherche de code.
- Ctrl+Alt+F / L / P : Fetch / Pull / Push.
- Ctrl+Q : demander la fermeture de l'application.

Les préférences permettent de personnaliser les valeurs. Un raccourci système peut intercepter la touche avant l'app. Aucun raccourci ne contourne confirmation, droits ou mode incompatible.

## Focus et édition {#focus-and-editing}
Tab/Maj+Tab parcourent les contrôles navigables au clavier. Les éditeurs gardent leurs touches normales ; une commande globale ne doit pas interpréter du texte saisi. Validez/annulez explicitement un brouillon avant d'en abandonner le contexte.

## Disposition et lisibilité {#layout-and-readability}
Redimensionnez colonnes/fenêtres, défilez horizontalement et détachez les panneaux denses. Réglez densité/police/DPI selon les possibilités et choisissez un thème contrasté. La couleur complète le libellé d'état, elle ne le remplace pas. View > Reset panel layout récupère un panneau hors écran. Signalez plateforme, échelle d'affichage et vue exacte si un problème de découpage persiste.
